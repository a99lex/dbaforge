# DBAForge

A lightweight Oracle and PostgreSQL DBA command center.

## v0.1
Searchable command reference for metadata, sessions, RAC, ASM, Data Guard, GoldenGate, RMAN, patching and PostgreSQL replication/performance.

## Local
```bash
npm install
npm run dev
```

## Static build
```bash
npm run build
```
Output is written to `out/`, suitable for static hosting.
